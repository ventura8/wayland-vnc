# wayland-vnc v1.0.4 - Snap and Flatpak for both architectures

The `wayland-vnc` package behaves exactly as in v1.0.3; the GNOME backend
`wayland-vnc-grd` as in v1.0.1. This release fixes what reaches you and how the
qualification lab reports itself.

## Highlights

- **The Snap and the Flatpak ship for amd64 and arm64.** Their names carried no
  architecture and one build replaced the other on the way to the release, so v1.0.0 to
  v1.0.3 each shipped a single `.snap` and a single `.flatpak`. They are now
  `wayland-vnc_1.0.4_<amd64|arm64>.snap` and `wayland-vnc-1.0.4-<x86_64|aarch64>.flatpak`,
  and the release fails rather than let two builds overwrite each other.
- **The Android qualification lab says when it is not ready.** With no emulator
  attached, a run used to fail every scenario and record the viewer as "unknown"; it
  now stops before starting anything and names the fix.
- **The headless container lab works with the runner.** It shares the host's emulator
  console token and clears the lock files a stopped lab leaves behind.

## Install

```sh
sudo add-apt-repository ppa:ventura8/wayland-vnc
sudo apt update && sudo apt install wayland-vnc
sudo apt install wayland-vnc-grd   # GNOME desktops
```

Or from the assets below -- `.deb`, `.rpm`, Arch `.pkg.tar.zst`, and per architecture
the AppImage, Flatpak, Snap and GNOME backend, with a `SHA256SUMS` manifest. Verify
first:

```bash
sha256sum --ignore-missing -c SHA256SUMS   # checks only the assets you downloaded
sudo apt install ./wayland-vnc_1.0.4_all.deb
```

## Status

**No desktop is release-qualified at this tag.** The gate stays red until all fourteen
target/viewer pairs pass on a trusted runner and their records are published to the
evidence store for the exact tagged commit. On earlier commits, the actual RealVNC
viewers, desktop and Android, passed every scenario on Sway, Wayfire, Xfce on labwc,
LXQt on labwc and every runnable one on KDE Plasma; GNOME all but `lock`, which GNOME
Shell refuses by design; Hyprland is blocked by an upstream aquamarine defect.
