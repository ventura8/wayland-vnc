# wayland-vnc v1.0.3 - Published everywhere again

The first release since v1.0.0 to reach both the PPA and GitHub. The `wayland-vnc`
package behaves exactly as in v1.0.2; the GNOME backend `wayland-vnc-grd` as in v1.0.1.

## Why there were no v1.0.1 and v1.0.2 releases

Launchpad's anonymous FTP accepted the first source upload of each release run and
refused the second (`wayland-vnc-grd`) with `550 internal server error`. The GitHub
release waits on the PPA upload, so neither tag was published, and the PPA kept the
GNOME backend at 1.0.0. Uploads now go over SFTP with the account's upload key and a
pinned host key, and a re-run skips a version Launchpad already has.

## What you get since v1.0.0

- **GNOME: a resize no longer freezes the session.** When the mirrored monitor changes
  size, `wayland-vnc-grd` now records it again and sends the viewer the new size, instead
  of leaving it on its last frame (from v1.0.1; on the PPA for the first time).
- **The AppImage embeds a pinned, checksummed runtime** instead of one downloaded
  unverified from a mutable release (v1.0.2).
- **The settings app** reads and writes its language preference as explicit UTF-8
  (v1.0.2).
- **Static analysis in CI**, and every SonarQube finding fixed in code, none suppressed:
  digest-pinned images, checksum-verified upstream archives, unprivileged lab images,
  HTTPS-only bounded downloads (v1.0.1, v1.0.2).

## Install

```sh
sudo add-apt-repository ppa:ventura8/wayland-vnc
sudo apt update && sudo apt install wayland-vnc
sudo apt install wayland-vnc-grd   # GNOME desktops
```

Or from the assets below -- `.deb`, `.rpm`, Arch `.pkg.tar.zst`, AppImage, Flatpak and
Snap, with a `SHA256SUMS` manifest. Verify first:

```bash
sha256sum --ignore-missing -c SHA256SUMS   # checks only the assets you downloaded
sudo apt install ./wayland-vnc_1.0.3_all.deb
```

## Status

**No desktop is release-qualified at this tag.** The gate stays red until all fourteen
target/viewer pairs pass on a trusted runner and their records are published to the
evidence store for the exact tagged commit. On the commits before it, the actual
RealVNC viewers, desktop and Android, passed every scenario on Sway, Wayfire, Xfce on
labwc, LXQt on labwc and every runnable one on KDE Plasma; GNOME all but `lock`, which
GNOME Shell refuses by design; Hyprland is blocked by an upstream aquamarine defect.
