# wayland-vnc v1.0.0 - Full installer, packaging, and CI/PPA automation

First packaged release of the evidence-gated, Wayland-only VNC compatibility toolkit
for the actual RealVNC Viewer.

## Highlights

- **Full installer product**: WayVNC systemd user service, enabled and started at
  install, listening on this machine only (`127.0.0.1:5900`) until Local Network
  Access is switched on in the settings app (then every interface, reachable from
  every network the machine is on); provisioning + diagnostics CLI, and a launcher
  TUI (install / diagnostics / uninstall).
- **Every package format**: `.deb`, `.rpm`, Arch, AppImage, Flatpak, Snap, sharing one
  payload staging script, with a `SHA256SUMS` manifest.
- **Real Docker install/uninstall smoke** across Ubuntu 26.04, Debian trixie,
  Fedora 44, AlmaLinux 10, openSUSE Tumbleweed, and Arch — happy and failure paths.
- **CI + release automation**: lint, unit+coverage, native ASan/UBSan, fixture-smoke
  and package-smoke matrices; tag-triggered PPA upload + GitHub release.
- **Isolated Wayland fixtures + unattended actual-viewer qualification** for GNOME, KDE
  Plasma, Xfce+labwc, LXQt+labwc, Sway, and Wayfire.
- **Settings app in 101 languages** with diacritics-tolerant search, verified RTL,
  and a translation lint that fails on any missing message.
- **`wayland-vnc-grd`**: the patched GNOME Remote Desktop backend for GNOME desktops,
  fixing five defects found with the real RealVNC Viewer (crash on disconnect,
  announced colour depth, stranded queued clients, stale pixel format, and the
  daemon killed mid-stream at 4K by the realtime watchdog).
- **Agent files and skills** and an expanded `AGENTS.md`.

## Install

Download the asset for your distribution from this release, verify it, then install:

```bash
sha256sum -c SHA256SUMS
sudo apt install ./wayland-vnc_1.0.0_all.deb           # Debian/Ubuntu
sudo dnf install ./wayland-vnc-1.0.0-1.*.noarch.rpm    # Fedora/EL
wayland-vnc-setup
```

Ubuntu 26.04 can instead use the PPA (`sudo add-apt-repository
ppa:ventura8/wayland-vnc`), which this tag populates with the same, not
release-qualified, build. On a GNOME desktop also install
`wayland-vnc-grd_1.0.0_amd64.deb` (or `_arm64.deb`). The server listens on this
machine only (`127.0.0.1:5900`) until you switch Local Network Access on — and
nothing fences it beyond that, so do not forward it through a router.
