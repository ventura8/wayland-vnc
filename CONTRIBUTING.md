# Contributing

Read [development](docs/development.md) and [testing](docs/testing.md). Keep changes
small and independently testable. Include failing regressions before fixes and
record exact desktop/backend versions for integration problems.

Do not submit personal connection files, APKs, screenshots, or credentials. Preserve
upstream copyright and license headers in patches. General correctness fixes should
be prepared separately from private compatibility policies for upstream review.

No stable compatibility claim is accepted without both actual RealVNC viewers.
Passing the Python suite, a protocol client, or a container startup is insufficient.
